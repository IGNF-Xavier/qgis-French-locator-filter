- Description:

Reverse geocoding using Géoplateforme from a vector layer.

- Parameters:

| Input                  | Parameter | Description                                              |
|-------------------------|-----------|----------------------------------------------------------|
| Input vector layer      | `INPUT`   | Input vector layer (point or polygon type).                         |
| Number of result for each feature     | `NB_RESULT_BY_FEATURE`      | Limitation of result number for each feature (default 1). |

- Outputs:

| Output                  | Parameter | Description                                  |
|--------------------------|-----------|----------------------------------------------|
| Output vector layer      | `OUTPUT`  | Vector layer with reverse geocoding. |

Processing name: `french_locator_filter:gpf_geocoder_batch`
