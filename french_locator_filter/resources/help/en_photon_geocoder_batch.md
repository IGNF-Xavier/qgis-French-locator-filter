- Description:

Address geocoding using Photon from a point vector layer.

- Parameters:

| Input                  | Parameter | Description                                              |
|-------------------------|-----------|----------------------------------------------------------|
| Input vector layer      | `INPUT`   | Input vector layer.                         |
| Address attribute       | `FIELD`   | Name of the attribute used for the address definition.   |

- Outputs:

| Output                  | Parameter | Description                                  |
|--------------------------|-----------|----------------------------------------------|
| Output vector layer      | `OUTPUT`  | Vector layer with address geocoding applied. |

Processing name: `french_locator_filter:photon_geocoder_batch`
