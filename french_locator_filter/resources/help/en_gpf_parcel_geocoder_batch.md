- Description:

Cadastral parcel geocoding (`parcel` index) using Géoplateforme from a point vector layer.

- Parameters:

| Input                  | Parameter | Description                                              |
|-------------------------|-----------|----------------------------------------------------------|
| Input vector layer      | `INPUT`   | Input vector layer.                         |
| Search attribute        | `FIELD`   | Name of the attribute used for the parcel search (cadastral identifier).   |

- Outputs:

| Output                  | Parameter | Description                                  |
|--------------------------|-----------|----------------------------------------------|
| Output vector layer      | `OUTPUT`  | Vector layer with parcel geocoding applied. |

Processing name: `french_locator_filter:gpf_parcel_geocoder_batch`
